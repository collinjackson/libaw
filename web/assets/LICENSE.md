# Placeholder art: license proposal

**Proposal only, not yet decided.** The sprites here (`sprites.svg`, `svg/`), `terrain-map.json` and
the skirmish map in `../states/` are original work, drawn by code in `make_sprites.py` and
`../states/make_skirmish.py`. They copy no Advance Wars or AWBW art. The idea is to release them
under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/), so anyone building a client
can use them without asking.

Unit and terrain names (`Infantry`, `Md.Tank`, `Orange Star HQ`, ...) are AWBW's identifiers, used
so the data stays compatible. Which names a game shows its players is that game's choice.
