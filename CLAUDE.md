# libaw

A clean-room Advance Wars By Web rules engine: `(state, action) -> state`, deterministic, no I/O.
Written to be published: everything here must be fine to open-source. Bots, betting, analysis,
sites and deploy kits live in other repos, not here.

## Clean room: read this first

- **Never read, clone, search, or fetch the source or docs of `carsonhu/awbw-ai`**, beyond
  its top-level README. Never paste its code here. This applies to every session and every
  subagent.
- Ground truth for the rules is **recorded AWBW games** (the replay API) plus AWBW's own pages
  and the AWBW wiki. When the engine disagrees with a replay, the replay wins.
- Other open-source projects may be read only after checking that their license allows it, and
  the license has to be noted in `docs/sources.md` first. GPL/AGPL code may inform
  understanding but is never copied.
- Rules cases and issues describe behaviour (what happens, with numbers), never AWBW's source.

## Layout

- `crates/engine`: the rules. `crates/replay`: the replay checker, local matches, storyboards.
  `crates/server`: the WebSocket game server. `crates/wasm`: the engine in the browser.
- `data/`: game data tables, generated by `tools/gen_data.py` from the sources in
  `docs/sources.md`.
- `tools/`: only engine tooling (data generation, the replay metrics, fetching replays).
- `docs/awbw-rule-findings.md`: what the rules review fixed and what is still open.
- Replays live outside the repo (a separate private data repo), never in it.

## Before a rules change lands

`cargo test --release`, then the replay checker (normal and `--step`) on the replay set before
and after: the change should fix games and break none.
